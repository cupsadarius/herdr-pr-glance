## Final whole-branch review and fixes

The final reviewer (Opus, high effort) found one P1 and two P2s that per-task gates missed:

1. P1: source identity compared the pane's foreground cwd and HEAD, so `cd` inside the
   checkout or a new commit reset the view and fired extra gh calls. Fixed in `ca9c666`:
   identity is workspace, tab, pane, checkout root, branch and empty reason; a new HEAD
   schedules one summary refresh without reset. Verified live: commit while Reviews open.
2. P2: `view` excluded only its own pane, so overlay over split could track the plugin
   checkout. Fixed in `af753bb`: overlay pane IDs recorded in `overlays.json`; `view`
   excludes every recorded Glance pane. Verified live.
3. P2: an empty `HERDR_PLUGIN_STATE_DIR` wrote state into the plugin checkout. `view`,
   `open` and `overlay` now exit with a clear error when it is unset.

The re-review of those fixes found two more: a pane switch within one checkout still reset
the view (pane removed from identity, `47966f2`), and recorded pane IDs were excluded without
a liveness check (excluded only while the live pane runs in the plugin root; records pruned on
`open`/`overlay`, `cf77341`). Re-review 2 verdict: READY_FOR_USER_REVIEW. Live checks at
`cf77341`: pane switch keeps Reviews open; overlay over split excludes the split correctly;
dead overlay record pruned on the next `open`.
